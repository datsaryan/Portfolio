## 🚀 Getting Started

No installation or build steps required. Just open it in a browser.

**Option 1 — Open directly:**
```
Open Final Portfolio/index.html in any modern web browser
```

**Option 2 — Clone and run:**
```bash
git clone https://github.com/datsaryan/Portfolio.git
cd Portfolio/Final\ Portfolio
open index.html
```
